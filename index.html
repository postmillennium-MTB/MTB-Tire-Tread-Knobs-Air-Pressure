Test conditions
Normal load 418 N for every test (95 kg rider on an 11 kg bike, 40 % on the front wheel). Tires ran on a small treadmill coated with non-skid tape; slip and camber were swept separately, never together.
Model equations
Pacejka Magic Formula (Eq. 2–4)
y = D·sin( C·atan( B·x − E·( B·x − atan(B·x) ) ) )
Y = y + SV   x = X + SH
BCD = slope at the origin = stiffness
FastBike twisting torque (Eq. 5)
MZTW(φ) = mr·φ·N·(1 + tw·φ²)
φ camber angle (rad), N normal load
Tangent rule (Eq. 6)
Fy / N = tan φ

Negative = the moment that turns the wheel back toward straight

FastBike polynomial: MZTW = mr·φ·N·(1 + tw·φ²)
The torque a leaned tire puts on the steering. A bigger value means more steering effort, which the paper links to the “autosteer” feel of fat bikes.
